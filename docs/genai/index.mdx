Concepts behind building with large language models. End-to-end "Design an AI assistant" style problems go in
[System Design](/docs/designs).

## Topics to cover
- LLM fundamentals: tokens, context window, temperature, transformers and attention at a high level
- Prompt engineering: system prompts, few-shot, structured output
- Embeddings and vector databases: similarity search, chunking, indexing
- RAG: retrieval pipeline, re-ranking, grounding, hallucination mitigation
- Agents: tool calling, MCP, multi-agent orchestration
- Fine-tuning vs. RAG vs. prompting
- Evaluation: offline evals, LLM-as-judge, guardrails
- Production concerns: latency, cost, caching, rate limits, observability, security (prompt injection)
